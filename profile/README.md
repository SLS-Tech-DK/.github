# SLS Tech

**AI- og cloud-implementering på Google Cloud.** København, grundlagt 2026.

Er I på Google? Så bygger vi det, I mangler — og lærer jer at køre det selv. Ingen enterprise-bureau-energi, ingen ansigtsløs freelancer. En navngiven, fuld-stack udvikler der sætter op, bygger ovenpå (automationer, apps, AI) og giver jer nøglerne. I ejer det selv.

Google er spidsen, ikke en mur: kører I noget andet, finder vi den bedste — og tit billigere — vej.

---

### Hvad vi bygger

Alt herinde følger den samme byggestandard: GitHub som single source of truth, adskilt sandbox og produktion, mobil **og** desktop, loading/tom/fejl-tilstande, GDPR og samtykke, secrets kun server-side, eget domæne + HTTPS. Ingen halve features — "klar" betyder testet og verificeret.
